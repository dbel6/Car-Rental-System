# Car Rental System

A team-based Java application designed to manage core operations within a car rental system, including handling company data through backend database functionality.

## Features
- CRUD operations (create, read, update, delete) for company management
- Database integration using MySQL
- Structured backend logic for data validation and processing
- Modular design as part of a larger system

## Technologies Used
- Java
- MySQL
- Git (version control)

## My Contribution
- Developed backend CRUD operations for managing company records
- Implemented SQL queries for inserting, updating and deleting data
- Worked as part of a team to integrate individual modules into a complete system

## What I learned
- Practical experience working with databases in real applications
- Improved understanding of backend development and data handling
- Collaboration using Git and team-based development
